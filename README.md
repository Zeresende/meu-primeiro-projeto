# Meu Primeiro Projeto

Projeto criado durante o aprendizado do Claude Code, com arquivos de front-end, dados e copy.

## Estrutura do projeto

```
meu-primeiro-projeto/
├── css/
│   └── style.css        — Reset e estilos base (body, h1, h2, p, botões)
├── js/
│   └── main.js          — Relógio em tempo real atualizado a cada segundo
├── data/
│   └── produtos.json    — Lista de 5 produtos de uma loja de cosméticos
├── copy/
│   └── email-boas-vindas.md  — Email de boas-vindas para newsletter
└── notas.md             — Ideias de projetos com Claude Code
```

## Tecnologias

- HTML5 / CSS3
- JavaScript (Vanilla)
- JSON

## Sobre

Projeto de prática desenvolvido com auxílio do Claude Code (Anthropic).
